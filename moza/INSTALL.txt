TelemFFB MOZA - installation
============================

TelemFFB with MOZA flight base support: telemetry effects (engine rumble, guns, gear,
buffeting, ...) play on a MOZA AB9 base (tested), in both Force Feedback and Force Sensing mode.
Other MOZA bases have no Force Sensing mode; with them TelemFFB MOZA works exactly like the
official TelemFFB (plain DirectInput) and does not need MOZA_SDK.dll.
Source and updates: https://github.com/AlexZabol/VPforce-TelemFFB (branch "moza").


1. Requirements (install once)
------------------------------
a) MOZA Cockpit - https://mozaracing.com (Downloads). It installs the MOZA DeviceService
   that TelemFFB talks to. Make sure the base works in MOZA Cockpit.
b) DirectLink - a separate free project that lets TelemFFB drive DirectInput force feedback
   devices of other makers, MOZA included (the same as for the official TelemFFB).
   Download the installer from https://directlink.flyfrisby.com and run it.
   (TelemFFB also links to it in System Settings > Integrations.)
c) MOZA SDK - https://mozaracing.com/pages/sdk (Flight SDK, file MOZA_SDK_x.x.x.x_en.zip).
   Only one file of it is needed (step 2). It is not included here: MOZA does not allow
   redistributing it.


2. Add MOZA_SDK.dll (once, AB9 only)
------------------------------------
MOZA_SDK.dll is one file of MOZA's free Flight SDK. MOZA does not allow sharing it, so it is
not in this zip: you get it from MOZA's website. Choose one way.

Automatic (recommended): connect the AB9 and start VPforce-TelemFFB.exe. If MOZA_SDK.dll is
   missing, TelemFFB asks whether to download the MOZA Flight SDK from mozaracing.com
   (about 100 MB). Answer "Yes". TelemFFB takes MOZA_SDK.dll out of the download, puts it
   next to VPforce-TelemFFB.exe and deletes the rest. TelemFFB MOZA updates keep it.
   - The newest Flight SDK on MOZA's SDK page is used. TelemFFB checks the file's checksum
     for SDK versions it already knows; for a newer version it shows the version and
     installs it only if you confirm.
   - No question appears if no AB9 is found, or if you ticked "Don't ask again" earlier.
     If the folder is not writable (for example under Program Files), unzip TelemFFB MOZA
     somewhere else, such as C:\TelemFFB-MOZA. In these cases you can also use the manual way.

Manual: download the Flight SDK zip (named MOZA_SDK_<version>_en.zip) from
   https://mozaracing.com/pages/sdk, then do A or B:

   A - script: right-click "add_moza_sdk.ps1" in this folder > "Run with PowerShell".
       It takes the newest MOZA_SDK_*.zip in your Downloads folder and copies MOZA_SDK.dll
       here. If the zip is saved elsewhere, give its path:
       powershell -ExecutionPolicy Bypass -File add_moza_sdk.ps1 -SdkZip "C:\path\to\MOZA_SDK_<version>_en.zip"

   B - by hand: open the zip and copy
       MOZA_SDK_<version>\MOZA_SDK\x64-release\bin\MOZA_SDK.dll
       into this folder, next to VPforce-TelemFFB.exe. Use the x64-release file, not x86
       or debug.


3. Start
--------
- Close the MOZA Cockpit window (its background service may keep running).
  TelemFFB and MOZA Cockpit cannot use the base at the same time.
- Do not run the official VPforce TelemFFB at the same time (see "Official TelemFFB too" below).
- Start VPforce-TelemFFB.exe. On first start:
  a) System Settings > Integrations: enable DirectLink.
  b) System Settings: select your AB9 as the joystick device. DirectInput devices are
     marked [DI] in the device lists.
  c) DCS (also IL-2 and BMS): like the official TelemFFB, DirectInput devices need the
     DirectInput Tap. Set it up on the Simulator Setup tab, on the page of each simulator.
- The log (Log menu) should show:  "MOZA: SDK effect channel open on 'AB9 Base'".
  If it says MOZA_SDK.dll is missing, repeat step 2.


4. Using it
-----------
- Basic Settings > "MOZA Base Mode" (AB9 only): Don't change / Force Feedback / Force Sensing.
  Like any TelemFFB setting it can be set per sim, class or aircraft (e.g. F-16 in Force
  Sensing); the base switches when the aircraft loads or when you change the setting.
- Effects work in both modes. Strength: the usual TelemFFB sliders and Effect Levels.
- Updates: at start TelemFFB checks the TelemFFB MOZA releases on GitHub (never the official
  TelemFFB, which would remove MOZA support); the status bar shows the version status and, if a
  newer release exists, TelemFFB offers to download and install it (MOZA_SDK.dll is kept).


5. Updating
-----------
Accept the update offer at start (or Utilities > Install Latest TelemFFB MOZA). Manually:
download the newest TelemFFB-MOZA-x.y.z.zip from https://github.com/AlexZabol/VPforce-TelemFFB/releases
and unzip it over this folder (MOZA_SDK.dll stays).


6. Official TelemFFB too
------------------------
Both can stay installed: put TelemFFB MOZA in its own folder (e.g. C:\TelemFFB-MOZA), never
over the official TelemFFB. They share the same settings (%LOCALAPPDATA%\VPForce-TelemFFB),
so aircraft settings carry over; the official TelemFFB ignores the MOZA-only settings.
Run only one of them at a time.
