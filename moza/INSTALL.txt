TelemFFB MOZA - installation
============================

TelemFFB with MOZA flight base support: telemetry effects (engine rumble, guns, gear,
buffeting, ...) play on a MOZA AB9 base (tested), in both Force Feedback and Force Sensing mode.
Source and updates: https://github.com/AlexZabol/VPforce-TelemFFB (branch "moza").


1. Requirements (install once)
------------------------------
a) MOZA Cockpit - https://mozaracing.com (Downloads). It installs the MOZA DeviceService
   that TelemFFB talks to. Make sure the base works in MOZA Cockpit.
b) DirectLink - TelemFFB's DirectInput bridge for non-VPforce devices. Download it from
   the link in TelemFFB: System Settings > Integrations.
c) MOZA SDK - https://mozaracing.com/pages/sdk (Flight SDK, file MOZA_SDK_x.x.x.x_en.zip).
   Only one file of it is needed (step 2). It is not included here: MOZA does not allow
   redistributing it.


2. Add MOZA_SDK.dll (once)
--------------------------
Easiest: just start VPforce-TelemFFB.exe. When MOZA_SDK.dll is missing, TelemFFB offers to
   download the MOZA Flight SDK from mozaracing.com (about 100 MB) and installs MOZA_SDK.dll
   next to the exe. Answer "Yes". (It stays there across TelemFFB MOZA updates.)
   The newest SDK on MOZA's site is used; a version whose checksum TelemFFB MOZA does not
   know yet is installed only after you confirm it.

Option A - script: right-click "add_moza_sdk.ps1" in this folder > "Run with PowerShell".
   It finds the MOZA SDK zip in your Downloads folder and copies MOZA_SDK.dll here.
   (Or run:  powershell -ExecutionPolicy Bypass -File add_moza_sdk.ps1 -SdkZip "C:\path\MOZA_SDK_1.0.0.6_en.zip")

Option B - by hand: open the MOZA SDK zip and copy
   MOZA_SDK\x64-release\bin\MOZA_SDK.dll
   into this folder, next to VPforce-TelemFFB.exe.


3. Start
--------
- Close the MOZA Cockpit window (its background service may keep running).
  TelemFFB and MOZA Cockpit cannot use the base at the same time.
- Do not run the official VPforce TelemFFB at the same time.
- Start VPforce-TelemFFB.exe. On first start, assign your MOZA base in System Settings
  (enable DirectInput devices if asked).
- The log (Log menu) should show:  "MOZA: SDK effect channel open on 'AB9 Base'".
  If it says MOZA_SDK.dll is missing, repeat step 2.


4. Using it
-----------
- Basic Settings > "MOZA Base Mode" (AB9 only): Don't change / Force Feedback / Force Sensing.
  Like any TelemFFB setting it can be set per sim, class or aircraft (e.g. F-16 in Force
  Sensing); the base switches when the aircraft loads or when you change the setting.
- Effects work in both modes. Strength: the usual TelemFFB sliders and Effect Levels.
- Updates: at start TelemFFB checks the TelemFFB MOZA releases on GitHub (never the official
  TelemFFB, which would remove MOZA support); the status bar shows the version status and, if a
  newer release exists, TelemFFB offers to download and install it (MOZA_SDK.dll is kept).


5. Updating
-----------
Accept the update offer at start (or Utilities > Install Latest TelemFFB MOZA). Manually:
download the newest TelemFFB-MOZA-x.y.z.zip from https://github.com/AlexZabol/VPforce-TelemFFB/releases
and unzip it over this folder (MOZA_SDK.dll stays).
